批改一份学生作业，产出可直接交付给学生的批改结果。

## 一、确认输入

- 需要两样东西：作业文件路径、学习者姓名。未指定时先询问，不要自行假定。
- 作业文件一般在项目根目录或 `grading/` 下。
- 解析时注意：题号可能跳号、选项编号可能错乱、题干与选项可能挤在同一行。
  一律按实际题目内容解析，不要按编号硬对齐；解析完先报告实际题量，与文件编号不符时说明原因。

## 二、建卷、定答案

- 按 `.trae/skills/gradable-quiz-generator/references/io-schema.md` 的字段契约，
  为每道题生成试卷 JSON，存入 `grading/quiz-<主题>.json`。
- 每题必须包含 `knowledge_point`、`answer`、`explanation`；解析要讲清干扰项为什么错。
- 答案键不确定时联网交叉验证，并在报告中注明依据来源。

## 三、命题自检（不可跳过）

执行：

```bash
python .trae/skills/gradable-quiz-generator/scripts/grade_quiz.py --quiz grading/quiz-<主题>.json --self-check --pretty
```

退出码非 0 或存在 error 项时，先修正试卷再继续，禁止带着错误进入批改环节。

## 四、批改

- 按学习者原始作答生成 `grading/answers-<学习者>.json`，未作答的题也要如实记录。
- 执行批改，报告 JSON 输出到 `grading/report-<学习者>.json`。
- 分数一律由 `grade_quiz.py` 判定，不得人工估算或凑分。

## 五、交付内容

1. 成绩总览：总分、得分率、等级、是否通过、答对/答错/未作答数。
2. 逐题明细表：序号、知识点、学习者作答、标准答案、判定、得分。
3. 错题分析：逐题给出选项辨析、知识对照、记忆要点，讲清"为什么错"。
4. 薄弱知识点排序与复习建议。
5. 产出文件清单与复现命令。

## 约束

- 错题分析不能只给正确答案，必须说明错因，以及易混知识之间的边界。
- 若答案键与教材或官方表述存在冲突，两种表述都列出，并说明取舍理由。
- 报告正文用中文、面向学生可读；机器可读数据单独存 JSON，两者不混在一起。
