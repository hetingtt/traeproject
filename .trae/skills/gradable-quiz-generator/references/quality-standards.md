# 命题质量标准与认知规律

生成题目时按本文件做自我校验。任何一条不满足，重写该题而不是降低标准。

---

## 1. 认知层级（Bloom 修订版）

每道题必须标注 `cognitive_level`，取值与设计动作：

| 层级 | 含义 | 题干动词 | 典型题型 |
|------|------|----------|----------|
| `remember` | 记忆 | 写出、列出、识别、指出 | 单选、填空、判断 |
| `understand` | 理解 | 解释、说明、举例、比较 | 单选、判断、简答 |
| `apply` | 应用 | 计算、使用、应用到、解决 | 填空、简答、单选 |
| `analyze` | 分析 | 分析、区分、归因、为什么 | 多选、简答 |
| `evaluate` | 评价 | 评价、判断优劣、论证 | 简答 |
| `create` | 创造 | 设计、构造、提出方案 | 简答 |

**整卷分布建议**（按题量自适应）：

- 随堂小测（≤10 题）：记忆/理解 ≥ 60%，应用/分析 ≤ 40%，不出评价/创造。
- 单元测验（10~25 题）：记忆 30%、理解 30%、应用 25%、分析 15%。
- 综合考试（>25 题）：记忆 20%、理解 25%、应用 30%、分析 15%、评价/创造 10%。

低层级题目不得占用过多分值；高认知层级题目应给更高 `points`。

---

## 2. 难度分级

`difficulty` 三档，以「目标学习者」为参照，不以题目绝对难易为准：

| 档位 | 判定标准 |
|------|----------|
| `easy` | 直接回忆单一知识点，题干无干扰信息，一步作答 |
| `medium` | 需要理解或简单迁移，需辨析 2 个相近概念，或两步作答 |
| `hard` | 需要多知识点综合、分析归因或方案设计，存在典型误区陷阱 |

难度分布：默认 3:5:2（easy:medium:hard）。用户指定难度时，全部题目落在该档位，但仍可混入 ≤20% 的相邻档位做区分度。

---

## 3. 题目编写红线

逐题检查以下各项，全部通过才算合格：

1. **单一考点**：一道题只考一个知识点，`knowledge_point` 只填一个。
2. **答案唯一**：不存在第二个可被合理辩护的正确答案；若存在，改写题干增加限定条件。
3. **题干自足**：不依赖上一题的结论或图片；不出现「如图所示」而无图。
4. **无答案泄露**：题干或某个选项的措辞不直接暴露正确项；选项间不互相暗示。
5. **语言规范**：不用双重否定（除非考逻辑）、不用生僻缩写、不使用「总是/从不」等绝对词（除非该知识点本身就是绝对命题）。
6. **选项同质**：同一题的选项在语法结构、长度、抽象层级上保持一致。
7. **无跨题重复**：整卷内不同题目不重复考查同一事实的同一侧面。
8. **答案解析齐备**：每题都有非空 `explanation`，说明「为什么对」而非只复述答案。
9. **知识点可归因**：`knowledge_point` 用词统一，便于按知识点统计薄弱项（同义不同名会拆散统计）。

---

## 4. 批改反馈规范

批改输出对每题必须包含四要素，缺一不可：

1. **判定结论**：得分 / 满分，是否正确。
2. **标准答案**：客观题给出答案键或答案值，简答题给出参考答案全文。
3. **错误分析**：说明学习者答案错在哪里，指向具体误区，而不是「回答错误」四个字。
   - 单选题优先引用 `distractor_rationale` 中对应干扰项的辨析。
   - 判断题引用 `misconception`。
   - 填空题指出第几空错、错在何处（概念错 / 单位错 / 表述不完整）。
   - 简答题列出 `missing_points`，并指出其与参考答案的差距。
4. **知识点讲解**：给出该题的 `knowledge_point` 与 `explanation`，帮助学习者建立正确认知。

整卷报告额外给出：

- 总分、得分率、等级、是否通过。
- 分题型得分（`summary.by_type`）与分知识点得分（`summary.by_knowledge_point`）。
- **薄弱知识点排序**：按得分率升序，取前 3 个，作为后续复习建议。
- **待复核题清单**：`needs_manual_review = true` 的题目及复核后的最终得分。

## 5. 质量自检清单（生成后执行）

- [ ] 每题的 `knowledge_point` 非空且用词统一
- [ ] 每题的 `difficulty` 与 `cognitive_level` 已标注，且整卷分布符合第 1、2 节要求
- [ ] 单选题正确键在 A/B/C/D 上分布均衡
- [ ] 多选题正确项为 2~3 个，且已注明评分方式
- [ ] 判断题真/假比例接近 1:1
- [ ] 填空题 `answer` 长度与题干空位数一致，且含同义答案
- [ ] 简答题 `rubric` 各项分值之和等于 `points`
- [ ] 每题 `explanation` 非空
- [ ] 整卷无重复考点、无答案泄露
- [ ] `python scripts/grade_quiz.py` 能对标准答案自评得到满分（见 SKILL.md 自检流程）
