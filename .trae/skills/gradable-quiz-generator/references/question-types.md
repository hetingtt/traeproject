# 题型规范与判定语义

五类题型共用一个 JSON 结构，差异集中在 `type`、`options`、`answer`、`grading`。
所有字段的完整定义见 `io-schema.md`。

---

## 1. single_choice（单选题）

| 字段 | 要求 |
|------|------|
| `options` | 4 个（低年级可 3 个），每项 `{key, text}`，key 用 A/B/C/D |
| `answer` | 单个选项键字符串，如 `"B"` |
| `distractor_rationale` | 可选，`{"A": "为什么 A 是错的", ...}`，用于生成针对性错误分析 |

**命题规则**
- 有且仅有一个最佳答案，其余三项必须是「貌似合理」的干扰项。
- 干扰项应来自真实错误认知（概念混淆、量纲错误、因果倒置、以偏概全），不要用明显荒谬的选项凑数。
- 避免「以上都对 / 以上都不对」，除非题目本身考查的就是该判断。
- 选项长度、句式尽量一致，不通过长度泄露答案。
- 正确选项在 A/B/C/D 上的分布要均衡（整卷内各键占比控制在 20%~30%）。

**判定语义**：作答可以是选项键（`"B"`）或选项原文（`"三次"`），归一化后精确匹配；未作答或无效选项记 0 分并给出提示。

---

## 2. multiple_choice（多选题）

| 字段 | 要求 |
|------|------|
| `options` | 4~5 项 |
| `answer` | 选项键数组，如 `["A","C","D"]` |
| `grading.partial_credit` | 默认 `false`（全对才给分）；置 `true` 时按漏选比例给部分分 |

**命题规则**
- 正确项数量控制在 2~3 个，避免全选或只选一个。
- 题干必须明确「多选」，并说明评分方式（全对得分 / 漏选给分）。
- 干扰项同样要具备诊断价值。

**判定语义**：作答顺序无关；开启部分分时 `得分 = 满分 × max(0, 命中数 − 错选数) / 正确项数`，错选会扣抵命中，得分下限为 0。

---

## 3. true_false（判断题）

| 字段 | 要求 |
|------|------|
| `answer` | 布尔值 `true` / `false`（不要写 `"正确"`） |
| `misconception` | 可选，一句话点出该题对应的典型误区 |

**命题规则**
- 陈述必须是明确可判定的，不含「通常」「可能」「一般来说」等模糊限定词。
- 真/假题比例在整卷内接近 1:1，避免学习者靠猜。
- 错误陈述要基于真实误区（如偷换概念、绝对化表述、因果颠倒），不要靠生僻细节制造错误。

**判定语义**：接受 `true/false`、`T/F`、`1/0`、`对/错`、`正确/错误`、`是/否`、`√/×`；无法解析时记 0 分并提示。

---

## 4. fill_blank（填空题）

| 字段 | 要求 |
|------|------|
| `answer` | 数组，每个元素对应一个空；元素为字符串表示该空唯一答案，为数组表示可接受的同义答案集合 |

示例：两个空，第一空接受「HTTP」或「超文本传输协议」，第二空只接受「80」

```json
"answer": [["HTTP", "超文本传输协议"], ["80"]]
```

**命题规则**
- 一个空只考查一个知识点，避免一空多义。
- 题干中空位用 `______` 表示，空的数量必须与 `answer` 长度一致。
- 必须列出同义答案（中英文、缩写全称、等价表述），否则会误判。
- 避免需要长篇表述的空；答案应短小且唯一。

**判定语义**：逐空比对，分值按空均分；大小写、全半角、标点、空白差异不影响判定；未作答的空按错误计入。

---

## 5. short_answer（简答题）

| 字段 | 要求 |
|------|------|
| `answer` | 参考答案全文（用于相似度提示与学习者对照） |
| `grading.rubric` | 评分要点数组，每项 `{point, keywords, score}`；各项 `score` 之和应等于 `points` |

**命题规则**
- 题干使用可操作的行为动词（简述、说明、比较、分析），明确作答范围与字数预期。
- 评分要点必须可观察、可计数，一般 3~5 个，覆盖「结论 + 依据 + 关键条件」。
- `keywords` 为命中该要点的同义关键词列表，任一命中即视为该要点得分。
- 为简答题配 `explanation`，说明满分答案的完整逻辑链。

**判定语义**：脚本只做关键词初筛，是**保守判定**——
- 命中全部要点 → 判满分，`needs_manual_review = false`；
- 部分命中或完全未命中 → 给出初筛分与相似度，`needs_manual_review = true`，**必须**由模型做语义复核后修正得分；
- 未提供 `rubric` → 一律转复核，脚本不给分。

复核时按 `references/quality-standards.md` 的反馈要求输出「得分 + 缺失要点 + 知识点讲解」。
